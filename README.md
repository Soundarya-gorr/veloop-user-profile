# VELoop User Profile Management System

## Project Overview
A full-stack user profile management application developed as part of the VELoop internship task.

## Technology Stack
- Python
- Flask
- MySQL
- Flask-SQLAlchemy
- PyMySQL
- Werkzeug

## Current Backend Features
- Flask API setup
- MySQL database connection
- User registration
- Password hashing
- User login and password verification
- User profile retrieval

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | / | Backend status |
| GET | /test-db | Test database connection |
| POST | /register | Register a user |
| POST | /login | Login a user |
| GET | /profile/<user_id> | Retrieve user profile |

## Project Status
Backend setup and initial user management APIs are completed. Frontend development, protected authentication, rewards functionality, admin panel, testing and deployment are planned next.
